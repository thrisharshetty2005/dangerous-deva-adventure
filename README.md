
# Dangerous Deva Adventure Game

A thrilling adventure game where you play as Dangerous Deva, explore mysterious worlds, overcome obstacles, collect rewards, and complete challenging levels.

## 🎮 Play the Game

👉 [Play Dangerous Deva Adventure](https://thrisharshetty2005.github.io/dangerous-deva-adventure/Dangerous_deva_adventure.html)

## 🕹️ Controls

- ← → / A D — Move
- ↑ / W / Space — Jump
- Collect coins and rewards
- Avoid obstacles
- Reach the goal to complete each level


# Core gameplay fixes 

- Sound- Web Audio sound effects for jump, coin pickup, bonus pickup, hurt and level clear fanfare

- Restart from level 1 on death- Now you respawn at the start of the current level only and progress is kept

- Modern pixel visuals- Gradient sky background, layered and shaded brick platforms coins that spin and a flag that waves

- Arrow-key-only controls- Added A and D keys for moving and W key for jumping as alternatives

- No real-time physics-Added gravity of 0.62, movement based on speed, momentum and friction of 0.82 damping

- Spacebar not mapped to jump-Space, Up Arrow and W all trigger jump

- No tutorial- Added a dedicated 'How to Play' screen that explains controls and goals

- Limited Devas- You can choose from 3 characters at the start of the game

- Limited rewards- Coins worth 10 points each and bonus stars worth 50 points each are placed in every level

- Can't go back- The camera scrolls in both directions so you can backtrack anywhere in a level

- No saving- The game auto-saves after each level you clear storing level number, score, lives and chosen character and there is a 'Continue' button, on the main menu

- No character change- The character select screen appears before you start a new game or continue

- Can't change direction mid-air- You have full control while jumping, not locked to the direction you started.
